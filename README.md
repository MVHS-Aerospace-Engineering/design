# design

Simulation of a twin-engine, high-wing RC plane (FT Radial 2218 motors with 2-blade props, one rudder, two stabilators, Pi 5 + flight controller bay), sized and analysed with AeroSandbox with XFLR5/AVL exports. Run `pip install -r requirements.txt && python -m twin_rc.sizing && python -m twin_rc.run_all`, then see `results/SUMMARY.md`; design inputs are in `twin_rc/config.py`.
